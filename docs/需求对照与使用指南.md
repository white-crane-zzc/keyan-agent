## 一、怎么启动、怎么用

### 1. 启动

双击项目根目录的 `启动.cmd`，或用命令行：

```powershell
cd E:\项目\科研小助手
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

浏览器打开 `http://127.0.0.1:8000`。启动脚本会自动拉起虚拟环境，不需要手动装依赖（依赖清单见 `requirements.txt`）。

大模型配置在根目录 `.env`：`LLM_BASE_URL` / `LLM_MODEL` / `LLM_API_KEY`。当前接的是 DeepSeek（`deepseek-chat`）。key 留空或还是占位串时，前端会显示「未接入大模型」，问答/翻译自动降级为「原文证据模式」——只给检索到的原文片段，不生成答案。改完 `.env` **必须重启服务**才生效。自检命令：

```powershell
.\.venv\Scripts\python.exe tests\check_llm.py
```

### 2. 使用顺序（按页签）

| 页签 | 干什么 | 关键操作 |
|---|---|---|
| 文库 | 上传、删除、看解析结果 | 拖多个 PDF 一次上传即为批量；重复论文会弹出「库里已有 / 新上传」的版本差异对比，可选保留库内、两个都留、取消 |
| 阅读 | 看原文 + 结构 | 左侧标题树点任意一级/二级/三级标题直接跳页；正文可划词翻译；整页可一键翻译 |
| 问答 | 单篇 / 多篇提问 | 在文库勾选论文（勾 1 篇=单篇问答，勾多篇=对比问答）；回答下方每条引用可点开定位到具体页 |
| 图谱 | 引用关系 | 一次勾 20 篇以上生成局部图谱，节点颜色区分「基石 / 中间 / 边缘」，可导出 |
| 写作 | 论文框架、架构图、数据图 | 输入 idea 生成 Abstract/Introduction/Related Work/References 框架；上传 CSV 生成折线/柱状/雷达图 + 图注 + 趋势结论 |
| 推荐 | arXiv 新论文 | 按库内论文方向推荐，标注是否含开源代码，可点赞/点踩反馈 |

### 3. 需求文档里的样例题，直接在「问答」页这样问

单篇（只勾 Attention 一篇）：
- 论文 Attention Is All You Need 的第6作者是谁，在哪个公司/机构工作？
- 这篇论文里 Adam 优化器的超参数 β1 和 β2 分别设置成了多少？
- 训练 Base 模型时用了多少个 GPU？具体是什么型号？
- Transformer (big) 在 English-to-German 上的 BLEU 是多少？当时的 SOTA 是多少？提升多少？
- 请列出论文中引用的关于 Layer Normalization 的参考文献的完整作者和年份。

多篇（勾 Attention + BERT，或 GPT-1/2/3）：
- BERT 的架构和原始 Transformer 的 Encoder 是什么继承关系？BERT 丢弃了哪个部分？
- 对比 GPT-1、GPT-2、GPT-3 的参数量变化。
- GPT-2 相比 GPT-1，在 Layer Normalization 位置上做了什么调整？
- 从 GPT-1 到 GPT-3，上下文窗口分别增长到多少？

## 四、当前已知质量限制

- 「超参数表 / 数值型」问题召回仍不稳：表格已入块，但中文问法与英文数值段词面不重叠，偶发答「材料未提及」，需人工核对原页或加向量检索。
- 双栏首页阅读顺序会打乱，作者序位类问题（第 6 作者）依赖模型从名单中数。
- 引用图谱依赖参考文献标题匹配，期刊论文的中文/非标准格式匹配率偏低。
